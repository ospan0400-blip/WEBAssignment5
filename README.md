# Web Assignment 5

## Description

This project contains HTML, CSS, and JavaScript exercises that demonstrate basic JavaScript functionality, DOM manipulation, event handling, and a simple to-do list application.

## Project Structure

```text
WEBAssignment5/
├── index.html
├── index1.html
├── index2.html
├── index3.html
├── script.js
└── style.css
```

## Project Parts

### Part 1 — JavaScript Basics
**File:** `index.html`, `script.js`

- Display an alert message.
- Print messages and variables to the console.
- Perform basic arithmetic operations.
- Work with strings and Boolean values.

### Part 2 — DOM Manipulation
**File:** `index1.html`

- Change paragraph text using a button.
- Change the background color of a container.
- Change the font size of text.
- Add and remove items from an ordered list.

### Part 3 — Events and Calculator
**File:** `index2.html`

- Change a box's color when the mouse enters or leaves it.
- Display text as the user types.
- Perform addition, subtraction, multiplication, and division.
- Handle division by zero.

### Part 4 — To-Do List
**File:** `index3.html`

- Add tasks with a title and description.
- All data stored in a array.
- Display tasks in a list.
- Mark tasks as completed by clicking their titles.
- Apply a strikethrough effect to completed tasks.
- Delete tasks from the list.

Tasks are stored temporarily in a JavaScript array, so they are not saved after the page is refreshed.

## Technologies Used

- **HTML5** — Page structure and input elements.
- **CSS3** — Styling and layout.
- **JavaScript** — Interactive functionality and DOM manipulation.
- **Bootstrap 5.3.3** — Layout, buttons, forms, and task cards in Part 4.

## How to Run

1. Download or extract the project files.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Open `index1.html`, `index2.html`, or `index3.html` to explore the other parts.

No additional installation is required.
